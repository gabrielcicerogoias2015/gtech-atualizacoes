# GTECH SYSTEMS – atualizações

Instaladores das versões publicadas dos programas GTECH (GMaps, versão Vivamar). Aqui não há código: só os instaladores, nos *Releases*, e os arquivos pequenos que os programas leem para saber se há versão nova.

- `gmaps-vivamar.json`: versão mais nova do GMaps (versão Vivamar), com o endereço e o SHA-256 do instalador.

Para instalar pela primeira vez, baixe o `GMaps-Setup-<versão>-Vivamar.exe` do release mais recente. Depois disso, o próprio GMaps avisa quando houver versão nova e pergunta se você quer atualizar.
